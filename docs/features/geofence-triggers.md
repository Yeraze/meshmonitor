# Geofence Triggers

Geofence Triggers act when a node enters, leaves or stays inside an area you draw on the map. There are two ways to set one up:

- **Automation Engine (recommended):** the **A node enters/leaves a region** trigger works across every source and can send Apprise notifications or run several actions. See [Geofence trigger](/features/automation-engine-reference#geofence-trigger).
- **Built-in Geofence Triggers:** set up per source in the **Automation** view. They send a message or run a script. See [Timer and Geofence Triggers](/features/automation-triggers#geofence-triggers), which has the [quick start](/features/automation-triggers#geofence-quick-start), token list and script arguments.
